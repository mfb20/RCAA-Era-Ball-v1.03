# RCAA ERA BALL v1.03

RCAA ERA BALL v1.03 builds on v1.01 with corrected historical rosters, expanded player profile images, a dedicated team reroll in Classic/Bench, and Nightmare Mode.

## v1.03 highlights
- Historical roster corrections for Seasons 1–6, 8–10, and 13–17, including newly added Season 5.
- Classic and Bench each have one Era + Team reroll and one Team-only reroll.
- Nightmare Mode: four picks, no rerolls, and the strongest historical rolls are removed from the pool.
- Nightmare Bowl and Nightmare Perfect Season achievements.

Open `index.html` locally or publish with GitHub Pages / GitHub Actions.
