# RCAA ERA BALL v1.03

RCAA ERA BALL v1.03 builds on v1.01 with corrected historical rosters, expanded player profile images, a dedicated team reroll in Standard/Bench, and Nightmare Mode.

## v1.03 highlights
- Historical roster corrections for Seasons 1–6, 8–10, and 13–17, including newly added Season 5.
- Standard and Bench each have one Era + Team reroll and one Team-only reroll.
- Nightmare Mode: four picks, no rerolls, with S6 CJSU, S10 Leopards, S2 KYS, and S4 OB removed from the roll pool.
- Nightmare Bowl Champion and LEGENDARY Nightmare Perfection achievements.
- Updated player profile art supplied for Kuhdd, Jude, Aki, Turbo, selected Static seasons, CJ S1–2, Noir S2–5, and Rac S11.

The deployed site is assembled by GitHub Actions from the pinned v1.01 base plus the v1.03 patch and profile-art sprite stored in this repository.
